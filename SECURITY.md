# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Once this repository is on GitHub, report them privately through its
**Security → Report a vulnerability** page. Until then, or if that isn't
possible, email milos300399@gmail.com with "SECURITY" in the subject.

Please include:

- what the problem is and where (file, feature or screen);
- steps to reproduce it;
- the impact you think it has (for example, a way to make DiskSweep select
  or remove a protected path, follow a junction or symbolic link, or edit
  the registry).

You'll get a reply as soon as possible. Please give a reasonable time to fix the issue before disclosing it anywhere.

## Please don't

- test against machines or data that aren't yours;
- access, change or delete data that isn't yours.

## Scope

Only the code in this repository and builds of DiskSweep made from it are in scope.
